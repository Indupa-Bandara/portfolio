Portfolio Risk Engine

Rust · C++20 · Rayon · AVX2 SIMD · Apache Parquet

  • Four VaR/ES models: historical simulation, EWMA normal, shrinkage normal Monte Carlo and Student-t Monte Carlo, plus component-ES attribution and stress scenarios.
  • Rolling 99% Kupiec and Christoffersen backtests on 1,825 daily returns for 20 Binance assets, 1,575 forecasts per model.
  • Rayon + SIMD took 430 ms against 1,895 ms for scalar Rust (about 4.4×) for 1M paths × 50 assets on an i5-1135G7. The C++ AVX2 backend was slower (5,846 ms, one thread) and is kept as experimental.

Reliable Multicast Market-Data Bus

Rust · UDP multicast · proptest · cargo-fuzz

  • One publisher, many subscribers, sequenced UDP multicast with NAK-based repair and strict in-order delivery.
  • Done: binary wire format with golden, property-based and fuzz tests; sans-IO recovery state machine; sequencer, retransmit log and rate-limited NAK server; deterministic simulated link; runnable sender and receiver over real UDP multicast; open-loop load generator.
  • Not yet done: SPSC ring buffer, recvmmsg, real network benchmarks, TLA+ model.

Latency results will be added once measured on Linux. Loopback numbers are not wire numbers.

Prototype (dev mode)

ZK-Verified Batch Auction

Rust · RISC Zero · Ed25519 · Merkle commitments

  • Deterministic uniform-price batch auction with explicit tie-breaks, price-priority and pro-rata allocation, Ed25519-signed orders, nonce checks and atomic net settlement.
  • A RISC Zero guest verifies host-supplied sorted-order witnesses and claimed fills instead of rerunning the matcher.
  • 16 matcher tests pass on Windows and Ubuntu; the dev-mode pipeline reported clearing price 101 and volume 15.

Signed orders → host (sort, witnesses) → RISC Zero guest → receipt with commitments → settlement

No real cryptographic proof has been generated yet. The real prover ran out of memory (exit code 137) on a 4 GiB VM. Prototype, not production software.
